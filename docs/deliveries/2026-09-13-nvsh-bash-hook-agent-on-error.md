# Delivery Summary — nvsh bash hook + agent on error

plan: `nvsh-bash-hook-agent-on-error` · run: `complete` · date: `2026-09-13`
baseline: `devague summary skeleton`

## Intent

> nvsh elevates your existing bash into a self-healing NVIDIA shell: install one sourced hook, keep bash exactly as it is, and when a command fails an NVIDIA-opinionated agent (Pi.dev driving the local associate model by default) appears inline with a diagnosis and a proposed fix you approve, retry and verify; /ask, /fix, /doctor and Ctrl+G reach the same agent on demand, and successful commands never pay a millisecond for it.

After: After 'nvsh setup', the operator's own bash is unchanged on success; a qualifying failure shows an inline ⚡ nvsh panel within a second with a diagnosis built from the real output slice and the machine's detected facts, offers a proposed fix that runs only after Enter, retries, and reports whether it worked; /ask, /fix, /doctor, /explain, /retry and Ctrl+G reach the same warm pi session; 'nvsh uninstall' removes everything.
